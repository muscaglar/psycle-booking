# First-run welcome — the four-page overlay and when it shows
Read this when you change the welcome, add a dialog that can open at launch (it must wait for this overlay), or drive a browser on a fresh profile. Skip it otherwise.

**First-run welcome** (js/app.js between the banners "Feature: First-run welcome" and "Feature: Timezone-aware travel notice"; `.onboard-*` in css/styles.css): a full-screen, four-page overlay — Welcome (the mark + wordmark, six tiles — five class types in their colours with their pictograms and the time tile — the headline "Find a class. Book a spot.", and the required "independent companion … not affiliated" sentence; every illustration is built from the Crisp primitives: `.ct-card` + `data-ct`, `.ct-tile`, `.t-time`, `.ct-badge`, the glow — pictograms through a `typeof classPictogram` guard, because tests run the block alone; its look is `crisp:9e-stats-membership` → 9e.8 over the `.onboard-*` rules in css/styles.css) · Find your class · Book in two taps · Keep up (widgets and reminders are named only when `Capacitor.isNativePlatform()`, and the Android app — `_onboardPlatform()` answers `'android'` — reads "with reminders and calendar sync" instead, since it has no widgets and is not an iPhone; "swipe between days" only on a touch screen — `_welcomePages(native, touch, platform)`, `(pointer: coarse)` — a mouse is told to "step through the days"). It keeps id `onboardOverlay`, class `onboard-overlay`, one `role="dialog" aria-modal="true"`, its own keydown handler (`_ownKeysOverlayUp` stands the shared one aside) and the `psycle_onboarded_v1` flag; z-index 9000 — above every app layer, under the Terminal / Blueprint texture (9999). Swipe, Next / Back, arrow keys; Skip always; the last page offers "Sign in with Psycle" (→ `openLoginPopup()`) + "Look around first", or a single "Done" for a signed-in replay; Skip, Escape, Look, Done and Sign in all write the flag; a double tap on Next cannot fire the finish button for 400ms after a page turn. `_welcomeDecision(facts)` (`pure:welcome`) → `show` | `done` (a stored token — presence of `psycle_bearer_token` / `psycle_bearer_token_enc` only — or a history of > 3: the flag is written silently, nothing shown) | `skip` (tests/smoke.html, a non-Discover `#tab` hash or active tab, a dialog / sheet already open: the flag is left alone) | `wait`. It is asked synchronously while app.js is evaluated (so a newcomer gets it INSTEAD of the app's first frames), again when `securityReady` settles, and a last time from the first-paint block; the first settled answer wins and nothing in that path may throw. iOS: localStorage may have been purged and native-bridge.js (the LAST script) restores it, so the first look answers `wait` and the overlay goes up as a wordmark-only cover (`is-holding`: no keys, no focus, `aria-hidden`); the second look reveals it or takes it down; a 5s fail-safe re-asks. It is only an overlay — `_dialogOpen()` does NOT count it, so search / restore / revalidation carry on underneath. The BACKGROUND dialogs check its id themselves and wait — it is full-screen and above `confirmModal`, so a dialog would open under it, take focus there, and one Escape would answer both: the waitlist "You're in" announcement (`_announceAllocations`), "Spot opened" (features.js `_showOpenedSpots`), the offline-booking ask, the two iOS reminder asks (before class; Mondays at 12:00) and the history-sync prompt. That prompt (`showHistorySyncPrompt`) goes by the overlay alone, not by a missing flag: a `skip` launch leaves the flag unset, and the newcomer who signs in there is still offered the sync. The overlay stops touch events propagating, so pull-to-refresh, swipe-to-cancel and the day pager never see a drag on it. Settings → Help → "Show the welcome again" (`replayOnboarding`) clears nothing. Browser checks on a fresh profile start behind it — seed `psycle_onboarded_v1='1'` (tests/README.md).
