# Swift — types and functions of the iOS targets
Purpose: per Swift file under ios-app/ios/App (Pods excluded): its types at any depth, and the functions / initialisers at the top level or directly inside a type, with line numbers. Read this when you touch the widget, Live Activity, intents, or the in-app Capacitor plugins. Skip it for web-only work. What each target does: agents/architecture/ios.md.

> Generated by agents/tools/build-index.mjs from working tree (uncommitted changes on top of `2301a76`). Do not edit; rebuild with `npm run agents:index`.

Paths are relative to ios-app/ios/App. Indentation = nesting. A value type (a struct, class or actor that is not a view, widget, intent, plugin or delegate) also lists its properties: "stored" is its SHAPE — for a `Codable` one a compatibility contract with payloads an older build wrote, so a new field is optional — and "computed" is where a stored string becomes something else (a snapshot time becomes a `Date` only in such a property). Properties of views (SwiftUI `body` included) and functions nested deeper are not listed. Any Swift edit must be re-proved with a simulator build before it ships.
